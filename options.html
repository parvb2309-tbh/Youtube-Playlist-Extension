YouTube Playlist Toolkit

Settings are stored in your browser (Chrome sync) and never sent anywhere except googleapis.com.

YouTube Data API key (optional)

Without a key the extension reads view counts from the page (rounded, e.g. “1.2M views”). With a key you get:
  • Exact view counts
  • Sorting by likes
  • Exact upload dates and durations
See API_KEY_GUIDE.md in the extension folder for how to create one (free).
